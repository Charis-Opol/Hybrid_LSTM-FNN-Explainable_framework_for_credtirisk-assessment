Attribution Flow & Decision Path

Two honest alternatives to a "chain-of-thought" view -- none of these models generate intermediate reasoning tokens the way an LLM does, so there's nothing literal to visualize as a reasoning trace. What's shown instead: how much of each branch's information actually survives to the final prediction (Sankey, from the ablation study), and, for the one model here where a real step-by-step decision chain genuinely exists, one borrower's actual path through one tree of the XGBoost ensemble.

Attribution flow: branch → fusion → prediction

Flow width = the ablation-based branch share (1 − correlation with real predictions when that branch is replaced by the training-fold mean). Reliable for both models, unlike per-feature Integrated Gradients, which didn't converge for most transformer borrowers.
